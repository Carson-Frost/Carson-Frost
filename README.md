- **[Gonzaga-Historical-Map](https://github.com/Carson-Frost/Gonzaga-Historical-Map)** is an interactive map of Gonzaga's campus across five eras, built in React with Leaflet.
- **[NFL-Data-Web-Scraper](https://github.com/Carson-Frost/NFL-Data-Web-Scraper)** pulls NFL stats, rosters, and schedules from nflfastR in R, one CSV per season back to 1999.
- **[seattle-public-transit](https://github.com/Carson-Frost/seattle-public-transit)** is a Streamlit dashboard over King County Metro's GTFS feed that compares real arrival times against the schedule.
- **[arcade-games](https://github.com/Carson-Frost/arcade-games)** is Pac-Man, Flappy Bird, and Pong in Java Swing, built by three of us in a week.
