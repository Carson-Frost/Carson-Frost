## Projects

- **[itm-scouting](https://github.com/Carson-Frost/itm-scouting)** is a fantasy football web app I
  started because I play fantasy football. I wrote it in Next.js and TypeScript, keep accounts and
  saved rankings in Firebase, and feed the pages from a SQLite warehouse of NFL data going back to
  1999 that a Python job refreshes on a schedule. It runs in Docker behind Caddy on a Linode server
  I manage, and I have designed, built, and run every part of it on my own since December 2025. The
  site's code is private, so this repository is the write-up and the screenshots.

- **[OurPL](https://github.com/Carson-Frost/OurPL)** is a small programming language I wrote in Java
  for a programming languages course. I wrote the lexer, the recursive-descent parser, and the
  tree-walking evaluator by hand instead of generating them from a grammar tool, and the lexer has
  61 JUnit tests that run on every push.

- **[Gonzaga-Historical-Map](https://github.com/Carson-Frost/Gonzaga-Historical-Map)** is an
  interactive map of Gonzaga's campus across five time periods, from the university's founding to
  today. Choosing a period redraws the map with the buildings that stood in those years. I built it
  in React and Vite, and the map itself is Leaflet.

- **[NFL-Data-Web-Scraper](https://github.com/Carson-Frost/NFL-Data-Web-Scraper)** is a set of R
  scripts that pull NFL season stats, weekly stats, rosters, and schedules from nflfastR, going back
  to 1999, and write one CSV per season. Each script takes a year or a range of years and handles
  the regular season, the playoffs, or both.

- **[seattle-public-transit](https://github.com/Carson-Frost/seattle-public-transit)** is a Streamlit
  dashboard for King County Metro's public transit data. It loads the GTFS feed into an in-memory
  SQLite database, then lets you browse trips by route and time and compare real arrival times
  against the schedule.

- **[arcade-games](https://github.com/Carson-Frost/arcade-games)** is a Java arcade with Pac-Man,
  Flappy Bird, and Pong behind one menu, written in Swing. Three of us built it in a week for a
  class, and it was the first game I ever made.
